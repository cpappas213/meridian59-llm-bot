server rules and automation permission. Before submitting a requested goal,
resolve only contract-required entities, validate the draft, use its canonical
form, add a fresh request ID, and choose activation from fresh status.

readiness, active goal/progress, internal phase, blocker candidates, proposals
reviewed, and any requested strategic mutation.
